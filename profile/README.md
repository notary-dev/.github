# notary-dev

Small open-source tools for networks and digital signatures, built by [Nacho Pola](https://github.com/NachoPola16) and [Martín Longares](https://github.com/martin05mlg), two telecommunications engineering students.

## Projects

| Project | What it is |
|---|---|
| [**notary**](https://github.com/notary-dev/notary) | Command-line tool that inspects the Spanish eID (DNIe), signs documents with standard CAdES-T signatures and RFC 3161 timestamps, and verifies them (X.509 chains, timestamps, OCSP). Python. |
| [**pingpoint-noc**](https://github.com/notary-dev/pingpoint-noc) | Self-hosted network operations centre: collects SNMP, syslog and IPFIX (plus Proxmox, Linux hosts, DNS and ICMP), stores it in SQLite, shows it in a web dashboard and alerts to ntfy, Discord, Slack, Telegram, webhook or email. Python, no Grafana or Zabbix. |
