# notary-dev

Open-source tools for digital signatures, built by [Nacho Pola](https://github.com/NachoPola16) and [Martín Longares](https://github.com/martin05mlg), two telecommunications engineering students.

## Projects

| Project | What it is |
|---|---|
| [**notary**](https://github.com/notary-dev/notary) | Command-line tool that inspects the Spanish eID (DNIe), signs documents with standard CAdES-T signatures and RFC 3161 timestamps, and verifies them (X.509 chains, timestamps, OCSP). Python. |
